# Патчер видео — сайт с авторизацией через Telegram

Готово: авторизация через бота @ineasy_4k_bot и страница-обработчик с локальным
предпросмотром видео (файл нигде не сохраняется, логика самой обработки будет
добавлена позже — сейчас просто заглушка с превью).

## Как это работает

1. Пользователь заходит на сайт и жмёт «Войти через Telegram».
2. Сайт создаёт сессию и открывает бота по ссылке `t.me/ineasy_4k_bot?start=SESSION_ID`.
3. Пользователь жмёт «Запустить» в Telegram — бот получает команду `/start SESSION_ID`,
   помечает сессию как подтверждённую и пишет пользователю «Успешно авторизовались,
   зайдите на сайт».
4. Сайт в фоне опрашивает сервер (раз в 2 секунды) и, как только сессия подтверждена,
   сам перекидывает пользователя на `/app.html`.
5. На странице обработчика в правом верхнем углу показывается Telegram ID,
   а в центре — зона «Ставьте сюда ваше видео» (drag-and-drop или клик).
   Файл читается только локально через `URL.createObjectURL`, на сервер не уходит.

## Как подключить своего бота и токен

1. Напишите **@BotFather** в Telegram → `/newbot` (если бота ещё нет) или используйте
   существующего **@ineasy_4k_bot**.
2. Получите токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
3. Скопируйте `.env.example` в `.env`:
   ```
   cp .env.example .env
   ```
4. Откройте `.env` и вставьте токен:
   ```
   BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   BOT_USERNAME=ineasy_4k_bot
   PORT=3000
   ```

## Запуск

```bash
npm install
npm start
```

Сайт поднимется на `http://localhost:3000`, а бот начнёт слушать команду `/start`
через long polling — отдельный вебхук настраивать не нужно.
